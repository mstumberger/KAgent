## 7. From the voice transcript of 2026-11-27

Fixed on this branch:

- [x] Parallel tool calls from Gemini's OpenAI-compatible stream (all under `index`
      0, each with its own `id`) were glued into one call with invalid arguments
      (`{"_raw": "{..}{..}"}`), so the call failed and the agent apologised twice. A
      new `id` on an index now starts a new call (`adapters/openai_chat.rs`).
- [x] `todo_write` replaces the list and the model sent only the new item each time,
      so every earlier item was lost. New `mode: "add"` appends; a replace that drops
      open items names them in the result.
- [x] Voice brain set back to `live` (Gemini Live thinks itself, as before S26). The
      default `routed` sends every utterance to the chat model as a text turn, which
      is slower and, with a non-voice chat model, less fluent.

Open:

- [ ] The alert session's first instruction ("investigate the alert") kept pulling
      the agent back to the alert while the owner asked for other things. The newest
      request of the owner should win.
- [ ] The agent cannot list or choose providers and models: `ui state` holds neither,
      so "select the NVIDIA provider" failed. Part of the voice settings item above.
- [ ] Identity: asked "did that come from Nemotron?", the model said it was "a language
      model developed by NVIDIA". The prompt should say it is KAgent and name the model
      it runs on.
- [ ] The agent said "I have noted you set the brain to Nemotron" without checking.
- [ ] `search_files` over `~` answered "no matches (exit 2)": exit 2 is an error of
      the search (unreadable folders), not "no matches".
- [ ] Speech to text: noise and short sounds come back as fragments in other languages
      (Hindi, German, Spanish, Italian). Constrain the transcription to Slovenian and
      English and drop fragments of one or two words that are not commands.
- [ ] `routed` as the default voice brain: decide the default (`live` or `auto`), or
      warn in Settings when the chat model is not a fast one.
